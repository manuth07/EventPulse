# EventPulse

EventPulse is a microservice-based event ticket booking system developed for the SE3022 Case Study Project.

## Technology Stack

- React.js
- ASP.NET Core Web API
- Entity Framework Core
- PostgreSQL
- YARP API Gateway
- Apache Kafka
- Docker
- Microsoft Azure
- GitHub Actions
- Azure Application Insights
- Stripe Test Mode
- Google OAuth 2.0

## Repository Structure

- `frontend/` - React frontend
- `gateway/` - YARP API Gateway
- `services/identity-service/` - Identity and user management
- `services/event-service/` - Event management
- `services/booking-service/` - Booking management
- `services/payment-service/` - Payment management
- `tests/` - Automated testing resources
- `infrastructure/` - Docker and Azure configuration
- `docs/` - Project documentation
